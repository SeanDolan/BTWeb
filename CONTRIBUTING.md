# Contributing

Keep GPIO assignments in the example's BoardConfig, supported by recorded board evidence. The BTWeb library must remain independent of specific hardware and Wi-Fi ownership. Run the firmware build and browser tests for protocol or transport changes.

Change firmware and browser parsers together when changing the wire format. Increment protocol version for incompatible changes and the service-worker cache version for web asset changes. Keep callbacks bounded and test disconnect/error paths, not just successful writes.

Before the first public library release, the owner should choose a licence, add repository/author metadata to `lib/BTWeb/library.json`, and record hardware acceptance results. The project does not claim certification or guaranteed BLE/ESP-NOW timing.
